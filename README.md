# Ionospheric Research

Исследования прогнозирования состояния ионосферы по данным ионозондов. Репозиторий объединяет материалы научных статей о краткосрочном прогнозе критической частоты слоя F2 — foF2 — и использовании наблюдений соседних станций.

## Исследования

### [Межстанционный прогноз foF2](interstation-forecast/README.md)

Оценка того, повышают ли измерения двух дополнительных станций точность прогноза при доступной локальной истории. Сопоставляются пять алгоритмов машинного обучения, несколько длительностей обучающего окна и последовательная проверка на более позднем периоде.

### [Компенсация пропусков наблюдений](gap-compensation/README.md)

Оценка пользы межстанционной информации при временной потере локальных измерений. Рассматриваются пропуски различной длительности, непрерывные отключения и задержки данных доноров.

## Общий подход

Исследования выполнены для станций EB040, DB049 и PQ052 на 15-минутной временной сетке. Каждая станция поочерёдно становится целевой, две остальные — фиксированными донорами. Используются LinearRegression, ElasticNet, RandomForest, XGBoost и CatBoost с фиксированными параметрами, без поиска гиперпараметров.

Модели переобучаются ежедневно только на прошлых данных. Январь–март 2026 года используется для сравнения окон 7, 21 и 28 суток; апрель–июнь — для подтверждающей проверки с окном 21 сутки. Основной показатель качества — средняя абсолютная ошибка MAE. Сравнения проводятся на общих временных выборках, а покрытие оценивается отдельно от точности.

Основной результат: польза соседних станций сильнее проявляется при недостатке локальных наблюдений. При полной истории выигрыш невелик и подтверждается не для всех станций. Результаты относятся к исследованным станциям и периодам и не означают универсальной переносимости.

В папке каждой статьи собраны её рукопись, результаты, рисунки, блокнот. Общая расчётная методика и проверки хранятся [отдельно](shared/README.md) без дублирования между статьями.

## Данные

[Общий набор данных](data/README.md) содержит исходные файлы GIRO для трёх станций за 2025 год и первое полугодие 2026 года, обработанные 15-минутные наблюдения и помесячные показатели покрытия. Данные хранятся в одном экземпляре для обеих статей.
