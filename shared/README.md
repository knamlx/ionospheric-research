# Общая методика и расчётные материалы

`protocol/nearby_pairs_2024_2025.json` фиксирует эксперимент: пары станций, календарные границы, параметры моделей, признаки, правила фильтрации и основные сравнения. Протокол использует только 2024–2025 годы.

`code/run_nearby_pairs.py` выполняет ежедневное скользящее переобучение и сохраняет результат каждой задачи отдельно. `code/analyze_nearby_pairs.py` проверяет исходные данные, рассчитывает покрытие и корреляции.

`diagnostics/nearby_pairs_2024_2025/` содержит проверку покрытия, расстояний и корреляций. `tests/test_nearby_runner.py` проверяет временную причинность, изоляцию пар, скрытие локальной истории и сохранение checkpoints без обучения реальных моделей.

## Воспроизведение

Из корня репозитория:

```powershell
.\run-nearby-pairs.ps1 -Action prepare
.\run-nearby-pairs.ps1 -Action run -Workers 12
```

Подробности, продолжение после остановки и формат результатов описаны в [RUN_NEARBY_PAIRS.md](../RUN_NEARBY_PAIRS.md). Рабочие результаты сохраняются в игнорируемом каталоге `local_data/nearby_pairs_run_2024_2025/`; итоговые диагностические материалы находятся в `diagnostics/nearby_pairs_2024_2025/`.
