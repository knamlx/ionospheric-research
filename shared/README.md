# Общая методика и расчётные материалы

Обе статьи основаны на одном последовательном эксперименте: 5415 задач, из них 4965 выполнены и 450 исключены из-за недостатка данных. Завершённый аудит подтвердил временную причинность, формирование признаков и обучающих медиан; повторно воспроизведены прогнозы 300 сохранённых моделей.

`code/` содержит общий расчётный движок и полный анализ эксперимента. `code/vendor/` — необходимые замороженные исходники формирования признаков и моделей. `protocol/` содержит протокол и фиксированные параметры, `validation/` — общие проверки. `provenance/file_map.json` фиксирует происхождение файлов и изменения структуры.

Таблицы статей разделены по сценариям: без искусственного пропуска — в первой статье, с пропуском — во второй. Основные подтверждающие сравнения разделены по номеру статьи. Таблицы и рисунки непрерывных отключений и задержек относятся ко второй статье; общие проверки и покрытие исходных наблюдений оставлены здесь. Общие результаты и код не дублируются.

## Просмотр сохранённых результатов

Среда исходного расчёта — Python 3.13; прямые зависимости зафиксированы в общем requirements.txt. Блокноты статей читают локальные таблицы и рисунки без обучения.

## Полный расчёт

Исходные архивы GIRO и обработанные наблюдения находятся в общей папке данных. Checkpoints, модели и pickle в набор не включены. Для полного анализа требуется отдельная рабочая копия завершённого эксперимента; её местоположение задаётся переменной `IONOSPHERIC_EXPERIMENT`. Если используются подготовка данных или повторный расчёт, базовый эксперимент отдельно задаётся через `IONOSPHERIC_BASELINE`. Эти переменные должны указывать на рабочие копии: расчётные функции создают и обновляют результаты. Импорт движка и просмотр готовых результатов обучения не запускают.

Доступные действия полного анализа перечисляются командой `python shared/code/analyze_experiment.py --help`. Оригинальные абсолютные пути в исторических реестрах сырых источников могут понадобиться для их полного хеш-аудита. Полное воспроизведение с нуля требует доступности архивов; переносимость одного только кода его не заменяет.

Адаптация исходников ограничена поиском локальных данных и интерфейсом запуска. Формулы, формирование признаков и параметры моделей сохранены. Рукописи и рисунки скопированы побайтно. CSV разделены по строкам без пересчёта метрик. Исторический итоговый аудит не запускался повторно при организации папок.
