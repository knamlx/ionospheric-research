# Данные ионосферных станций

Общий набор данных для обеих статей. Станции: EB040, DB049, PQ052. Период: январь 2025 — июнь 2026. Источник наблюдений — GIRO.

## Исходные наблюдения

В `raw/` сохранены все 21 исходный текстовый файл, использованные завершённым экспериментом. Файлы сгруппированы по станции и году: для каждой станции один годовой файл за 2025 год и шесть месячных файлов за первое полугодие 2026 года. Ответы GIRO сохранены без изменений, включая заголовки, показатели качества и исходные пропуски.

## Обработанные данные

`processed/observations_15min.csv` — единая таблица с колонками `time_utc`, `EB040`, `DB049`, `PQ052`. Время — UTC, значения foF2 — в МГц. Временная отметка обозначает начало 15-минутного интервала. Пустая ячейка означает отсутствие принятого наблюдения; исходные пропуски не восстанавливаются.

В исходной обработке применены фильтры качества и допустимых значений foF2, затем наблюдения агрегированы на 15-минутную сетку. Заполнение медианами выполняется позднее при обучении моделей и не изменяет эту таблицу наблюдений.

`monthly_valid_bins.csv` содержит число непустых интервалов по месяцам, `monthly_coverage_percent.csv` — их долю в процентах. Таблица наблюдений скопирована из завершённого эксперимента и проверена на совпадение с его внутренней панелью.

`manifest.json` содержит относительные имена, размеры и SHA-256 файлов. Сырые и обработанные данные хранятся по одному экземпляру и используются обеими статьями. Производные кэши признаков, обученные модели и промежуточные запуски сюда не входят; код формирования признаков сохранён в общей расчётной части.
