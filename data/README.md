# Данные ионосферных станций

Общий набор данных для обеих статей. Период наблюдений: 01.01.2024–31.12.2025 UTC. Станции: PQ052 (Pruhonice, Чехия), SO148 (Sopron, Венгрия), IC437 (I-Cheon, Республика Корея) и JJ433 (Jeju, Республика Корея). Источник — GIRO.

## Исходные наблюдения

В `raw/` находятся 12 текстовых ответов GIRO: по три файла для каждой станции (первое и второе полугодия 2024 года и 2025 год). Содержимое сохранено без изменения. Окончание `2026-01-01` в имени файла за 2025 год является исключающей верхней границей, а не данными 2026 года.

## Обработанные данные

`processed/observations_15min.csv` — единая таблица с колонками `time_utc`, `PQ052`, `SO148`, `IC437`, `JJ433`. Значения foF2 приведены к 15-минутной сетке UTC и выражены в МГц. Пустая ячейка обозначает отсутствие принятого наблюдения; пропуски в файле не восстанавливаются.

При подготовке исключаются неконечные значения, foF2 вне диапазона 0,5–25 МГц и измерения с CS < 50. Значения с CS=999 принимаются как ручные; CS=-1 не принимаются. Заполнение медианами выполняется только внутри обучающего окна модели и не изменяет таблицу наблюдений.

`manifest.json` содержит метаданные станций, относительные имена, размеры и SHA-256 исходных файлов. Производные кэши признаков, обученные модели, checkpoints и результаты длительного расчёта в каталог данных не включены.
