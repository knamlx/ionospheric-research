# Межстанционный прогноз критической частоты foF2

## Задача

Исследуется, насколько наблюдения соседних ионосферных станций улучшают краткосрочный прогноз foF2 при доступной локальной истории. Локальная модель использует только прошлые измерения целевой станции, межстанционная — дополнительно измерения двух фиксированных доноров.

## Данные и методика

Рассматриваются станции EB040, DB049 и PQ052. Наблюдения приведены к сетке 15 минут; прогнозируется среднее foF2 следующего 15-минутного интервала. Каждая станция поочерёдно становится целевой. Доноры не выбираются по ошибкам на тестовой выборке.

Сравниваются LinearRegression, ElasticNet, RandomForest, XGBoost и CatBoost с фиксированными параметрами. Признаки включают лаги и изменения foF2; медианы для заполнения пропусков вычисляются только по обучающим данным. Ежедневное переобучение использует доступную к началу тестового дня историю.

В январе–марте 2026 года сопоставляются окна обучения 7, 21 и 28 суток. В апреле–июне выполняется подтверждающая проверка с окном 21 сутки. Все окна сравниваются на общей временной выборке: в частности, исключены 134 дополнительных момента PQ052, доступных только для окна 28 суток. Основной подтверждающий контраст — линейная регрессия без искусственного пропуска локальных измерений.

## Результаты

| Станция | Локальная MAE, МГц | Межстанционная MAE, МГц | Снижение MAE |
|---|---:|---:|---:|
| EB040 | 0,2226 | 0,2193 | 1,49% |
| DB049 | 0,1259 | 0,1232 | 2,10% |
| PQ052 | 0,1878 | 0,1828 | 2,67% |

Неопределённость оценена парным круговым bootstrap календарных блоков, 2000 повторов. При семисуточных блоках и поправке на три станции положительный эффект подтверждается только для PQ052. Для EB040 и DB049 интервалы включают ноль.

Добавление доноров даёт небольшой выигрыш, но не подтверждает универсального преимущества при полной локальной истории. Интерпретация ограничена тремя станциями, длительностью подтверждающего периода и нестационарностью ионосферы.
